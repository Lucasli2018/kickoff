# 起步 · Kickoff

专治拖延的极简 PWA。核心不是「做完」，而是「开始」——拖延最大的坎是启动阻力，两分钟足够跨过去。

## 它怎么做

1. 写下此刻要做的一件小事（也可用快捷预设，或点「给我一件小事」随机生成）
2. 选一个**时长**（默认 2 分钟，另有 1 / 5 分钟）和**归类**（工作 / 学习 / 生活 / 随手，可留空）
3. 点「启动 2 分钟」进入全屏极简倒计时，圆环与浏览器标签页动态图标同步显示进度
4. 提前完成点「我完成了」，自然到点会双音提醒；确认后撒花、+10 分、写入记录

**不要求做完，只要开始；中途放弃不扣分、不惩罚。**

## 功能一览

### 抗拖延
- **2 分钟启动法**：专注「跨过第一步」，不谈完成率；时长可按习惯切到 1 或 5 分钟，偏好自动记住
- **随机微行动**：不知道做什么时一键填入极小行动（「打开文件，光标放进去」「写下第一行」…），自动避开连续重复
- **切回提醒**：倒计时中切走再回来，温柔提示剩余时间；切到别的标签也能从动态图标看到倒计时
- **温柔容错**：提前完成照常计入；「放弃」不扣分、不打断

### 坚持感
- **游戏化**：积分、6 级等级（起步者 → 从容者）、连续天数与最佳纪录、6 枚成就徽章
- **每日目标**：每天 3 次启动，统计卡实时显示 `0/3 → 今日已达标 ✓`
- **7 天轨迹**：日历式热力条，浅 → 深四档，一眼看出哪天动了、哪天没动
- **本周归类**：按最近 7 天统计工作 / 学习 / 生活 / 随手各启动几次，条形图直观看到精力去向
- **累计专注**：按实际启动秒数累计分钟数；最近记录可单条删除，相关统计同步回退
- 每日一句鼓励语轮换

### 数据与体验
- **数据备份**：底部弹框整合导出 JSON / 从 JSON 恢复 / 清空；导入带格式校验，坏文件不会让应用崩溃
- **记录可删**：每条记录右侧 × 删除，积分、连续天数、热力条、每日目标、专注时长同步回退（成就一旦解锁永久保留）
- **网页图标**：静态 `favicon.svg` / ICO；倒计时中标签页图标变成进度圆环 + 剩余秒数，结束自动恢复
- **提示音**：完成音与到点双音提醒，可一键关闭；尊重系统「减少动态效果」设置
- **快捷键**：桌面端空格启动、Esc 退出
- **极简清爽**：白底 + 墨青单色强调，无广告、无干扰
- **本地存储**：数据只在这台设备上，零后端、离线可用、隐私可控

## 手机安装

1. 用手机浏览器打开部署后的网址。
2. 菜单 → 「添加到主屏幕」/「安装应用」（首页底部也会出现安装按钮）。
3. 像普通 App 一样全屏使用，断网也能打开。

## 本地运行

```bash
python -m http.server 8899
# 浏览器打开 http://localhost:8899
```

> 需要用 HTTP 访问，PWA 的 Service Worker 在 `file://` 下不生效。

## 部署

纯静态站点：部署到 Cloudflare Pages，构建命令留空，输出目录填项目根目录即可。

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件应用，内联全部 CSS/JS |
| `manifest.webmanifest` | PWA 安装配置 |
| `sw.js` | Service Worker，离线缓存（缓存名随版本升级） |
| `favicon.svg` | 浏览器标签页矢量图标 |
| `icons/` | favicon.ico + 192 / 512 / apple-touch 图标 |
| `tools/gen_icons.py` | 图标生成脚本（改主题色后重跑即可） |

数据键：`localStorage.kickoff_data_v1`。旧版本数据在启动时自动补齐新字段，无需手动迁移。
