# 起步 · 两分钟启动器

专治拖延的极简 PWA。核心不是「做完」，而是「开始」。

## 功能

- **2 分钟启动**：写下一件小事，点一下进入倒计时，只要求开始，不要求完成。
- **温柔容错**：提前完成照常计入；中途放弃不扣分、不惩罚。
- **游戏化激励**：积分、等级（Lv.1 起步者 → Lv.6 从容者）、连续天数、6 枚成就徽章、完成撒花与提示音（含到点双音提醒）。
- **坚持轨迹**：每日 3 次小目标 + 最近 7 天启动热力条，一眼看见自己在往前走。
- **随机微行动**：不知道做什么时点「给我一件小事」，一键填入一个 2 分钟内能做完的极小行动。
- **切回提醒**：倒计时中途切走再回来，会温柔提示剩余时间（标签页图标也同步显示）。
- **数据备份**：底部「数据备份」里可导出 JSON / 从 JSON 恢复 / 清空；换机或清浏览器前记得导出。
- **记录可删**：最近启动列表每条右侧可删除，积分与统计同步回退。
- **累计专注**：显示累计专注分钟数；桌面端空格启动、Esc 退出，并尊重系统「减少动态效果」设置。
- **网页图标**：静态 favicon（SVG/ICO）；倒计时开始后标签页图标变成圆环 + 剩余秒数，切到别的标签也看得见。
- **本地存储**：数据存在手机浏览器里，零后端、离线可用、隐私可控。
- **极简清爽**：白底 + 墨青单色强调，无广告、无干扰；每日一句鼓励语轮换。

## 手机使用

1. 用手机浏览器打开部署后的网址。
2. 菜单 → 「添加到主屏幕」/「安装应用」（首页底部也会出现安装按钮）。
3. 像普通 App 一样全屏使用，断网也能打开。

## 本地运行

```bash
python -m http.server 8899
# 浏览器打开 http://localhost:8899
```

> 需要用 HTTP 访问，PWA 的 Service Worker 在 `file://` 下不生效。

## 部署

纯静态站点：部署到 Cloudflare Pages，构建命令留空，输出目录填项目根目录即可。

## 结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件应用，内联全部 CSS/JS |
| `manifest.webmanifest` | PWA 安装配置 |
| `sw.js` | Service Worker，离线缓存 |
| `favicon.svg` | 浏览器标签页矢量图标 |
| `icons/` | favicon.ico + 192 / 512 / apple-touch 图标 |
| `tools/gen_icons.py` | 图标生成脚本（改主题色后重跑即可） |

数据键：`localStorage.kickoff_data_v1`。
