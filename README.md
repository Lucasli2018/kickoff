# 起步 · 两分钟启动器

专治拖延的极简 PWA。核心不是「做完」，而是「开始」。

## 功能

- **2 分钟启动**：写下一件小事，点一下进入倒计时，只要求开始，不要求完成。
- **温柔容错**：提前完成照常计入；中途放弃不扣分、不惩罚。
- **游戏化激励**：积分、等级（Lv.1 起步者 → Lv.6 从容者）、连续天数、6 枚成就徽章、完成撒花与提示音。
- **本地存储**：数据存在手机浏览器里，零后端、离线可用、隐私可控。
- **极简清爽**：白底 + 墨青单色强调，无广告、无干扰。

## 手机使用

1. 用手机浏览器打开部署后的网址。
2. 菜单 → 「添加到主屏幕」/「安装应用」（首页底部也会出现安装按钮）。
3. 像普通 App 一样全屏使用，断网也能打开。

## 本地运行

```bash
python -m http.server 8899
# 浏览器打开 http://localhost:8899
```

> 需要用 HTTP 访问，PWA 的 Service Worker 在 `file://` 下不生效。

## 部署

纯静态站点：部署到 Cloudflare Pages，构建命令留空，输出目录填项目根目录即可。

## 结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件应用，内联全部 CSS/JS |
| `manifest.webmanifest` | PWA 安装配置 |
| `sw.js` | Service Worker，离线缓存 |
| `icons/` | 192 / 512 / apple-touch 图标 |
| `tools/gen_icons.py` | 图标生成脚本（改主题色后重跑即可） |

数据键：`localStorage.kickoff_data_v1`。
